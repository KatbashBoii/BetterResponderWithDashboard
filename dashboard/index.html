      Where the data comes from

      Data file
      dashboard\data\bot-data.json (full history) and bot-data.js (same data for this page). Written by UpdateDashboard.xaml.

      Open on start
      Main.xaml variable openDashboardOnStart (default True) opens this page when the bot starts.

      Close the page, delete the two files in dashboard\data, and run the bot again.
